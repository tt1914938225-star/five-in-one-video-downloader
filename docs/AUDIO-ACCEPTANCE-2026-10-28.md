# 2026-10-28 音频入口修复

用户截图样本：`https://v.douyin.com/CXxjoOZkPhk/`，展开后的作品 ID 是 `7150996832137612556`。

## 原因

生产接口返回两个未标明类型的链接。实测两者均为 `video/mp4`，没有独立音频地址。第一个视频约 12.7 MiB 可下载；第二个超过 18 MiB，之前显示“未确认资源 2”。这不是一个可用音频按钮被隐藏，也不能把第二个视频伪装成音频下载。

## 修改

- 音频区保留实际独立音频，同时为每个有效视频提供“提取音频”。点击后取回已验证的视频，在浏览器中只复制首选音轨并生成真实音频文件；不会修改 MP4 后缀冒充 MP3。
- AAC → M4A，MP3 → MP3，Opus/Vorbis → OGG。不重新编码、不混音；多音轨仅选首选音轨。
- 增加进度、取消、无音轨/受保护/格式/超时/过期/超限错误。重新解析取消旧任务并释放本地 Blob URL，避免音频串到另一篇作品。
- 读取视频和输出均限定 18 MiB，单次处理 30 秒、最多一个提取任务；源站下载与访问保护继续按原规则校验。
- 超限前已通过 MIME 与文件头识别的资源保留真实类型，超限的视频不再放到“未确认资源”，仍不提供无效下载按钮。
- 新增 Mediabunny 1.62.1，浏览器按需加载的构建模块约 304 KiB；完整许可证随静态资源发布，未修改依赖源码。没有引入 VPS、转码服务或新的 API 密钥。

## 验证

- 本地类型/语法、静态构建、五个 Functions 打包通过。
- 130 项离线测试通过。新增有声文件的编码包和时长保持一致、无声不生成假音频、损坏与超限拒绝、受保护合成音频拒绝、提取取消，以及超限视频类型保留测试。
- 合成夹具由 FFmpeg 生成（0.25 秒 440 Hz 测试音/黑色视频）；受保护夹具仅加密这段自有测试音，不提供解密密钥。FFmpeg 不进入项目运行依赖或部署包。
- 用户真实样本取回 13,302,697 字节视频，提取成 4,714,207 字节 M4A，AAC、44.1 kHz、双声道、291.271111 秒，输出仅 1 个音轨、0 个视频轨。
- 本地浏览器在与生产一致的 CSP 下，用该真实视频完成提取：音频显示 M4A、4:51、4.5 MiB，浏览器读取 291.271111 秒、readyState=4、无媒体错误；实际播放推进至 34.49 秒后暂停。取消后可重试；新解析会取消旧任务、清除旧音频播放器，未出现旧结果覆盖。
- 浏览器下载事件已捕获，文件实际保存到用户下载目录；落盘大小为 4,714,207 字节。容器生成时间等元数据可不同，另比较提取后的编码音频包哈希、包数及时长，确认实际音频一致。本次没有读取浏览器下载历史。
- 本地平台解析响应使用模拟数据，音频处理用真实视频；Netlify Preview 仍需独立验收，不以本地模拟代替线上集成验证。
